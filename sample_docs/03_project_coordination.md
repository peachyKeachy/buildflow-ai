# SYNTHETIC SAMPLE: Project Coordination

## Weekly coordination
The fictional coordination lead Nia Ortiz chairs a trade coordination meeting each Tuesday at 09:30. Each trade provides an updated constraint list by Monday at 15:00. Review unresolved routing conflicts, access zones, submittal dependencies, and decisions needed before the next installation sequence. A meeting action is not a formal design response.

## Decision ownership
Assign one named owner and a target review date to every coordination action. The superintendent owns installation sequencing; the design coordinator routes design questions to the appropriate designer. Questions requiring a design interpretation become RFIs. Product data and shop drawings requiring acceptance use the submittal process instead.

## Shared action record
Record the issue number, location, source drawing revision, assigned owner, target date, and next action in the coordination log. Keep the unresolved item open until the responsible reviewer provides a documented decision. Never close an issue solely because it was discussed in a meeting.
