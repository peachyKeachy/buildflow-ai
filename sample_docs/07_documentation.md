# SYNTHETIC SAMPLE: Documentation and Reporting

## Daily report cutoff
The fictional field coordinator publishes the daily construction report by 18:00 local project time. Include work areas, trade activities, manpower observations, deliveries, weather effects, unresolved constraints, and photographs with locations. State unavailable information explicitly rather than estimating it. The report is a dated snapshot, not a live data feed.

## File naming
Name evidence files PROJECT-ISSUE-YYYYMMDD-REV, with a short descriptive suffix if needed. Include the drawing number and revision in the record metadata. Keep superseded revisions in the archive, mark them obsolete, and link the current revision. Do not overwrite historical decisions or reuse an issue identifier for another condition.

## Status reconciliation
Before a weekly report, compare the coordination log with the RFI register and submittal log. Explain differences instead of copying stale counts. The structured RFI register is the source for current RFI counts and criticality; narrative meeting notes are dated observations. No approved project budget, bank information, or contract completion date is included in this synthetic knowledge base.
