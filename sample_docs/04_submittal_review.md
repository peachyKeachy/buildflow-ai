# SYNTHETIC SAMPLE: Submittal Review

## Review window
The fictional project engineer performs an initial completeness check within two working days of receiving a submittal. The sample design-review target is five business days after a complete package is accepted for review. These are demonstration targets, not contractual commitments. An incomplete package is returned with specific missing items; its review clock does not start.

## Required package
A complete submittal includes the specification section, product data or shop drawings, drawing references, highlighted deviations, trade review stamp, and requested return date. Record the package revision and any long-lead procurement dependency. This package is separate from the Cedar RFI escalation packet.

## Resubmission
For a revise-and-resubmit disposition, highlight every changed item and retain the previous reviewer comments. Preserve prior revisions for audit, but show the most recent accepted revision for installation planning. A submittal review does not approve an undocumented field change.
